# kurashi-mamorite-test
暮らしのマモリテWebサイト制作テスト

## 確認方法
1. リポジトリ直下で `index.html` をブラウザで開きます。
2. デザインが適用されていることを確認します（`style.css` が読み込まれている状態）。
3. ヘッダー・各セクション・フッターの表示、およびページ内リンクの遷移を確認します。

## CSS作業メモ
- サービス内容ページPC版は現状維持の基準として仮固定しています。料金ページ制作では `price-hero-*`、`price-plan-*`、`price-guide-*`、`price-note-*`、`price-cancel-*`、`price-contact-*` の専用classを使用し、`service-title-*`、`service-daily-*`、`service-food-*`、`service-totonoe-*`、`service-combination-*`、`service-consultable-*`、`service-contact-*` のCSSは変更しない方針です。
